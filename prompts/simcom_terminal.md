# CyberForge SIMCOM Surface

SIMCOM emulates a defensive command terminal over the current CyberForge report.

Supported intents:

- `bootcom`: simulated fabric status
- `status`: model, vault, crypto, and provider state
- `scan`: run authorized digital-twin simulation
- `timeline`: highest relative pressure windows
- `impact`: affected-equivalent operational range
- `hotspots`: named or optional-coordinate concentrations
- `paths`: trust-path amplification
- `council`: model consensus and disagreement
- `origin`: explain why simulation cannot establish attribution
- `export`: return the signed/digested structured report

Every output must retain the labels “simulated,” “predictive,” or “modeled” where appropriate. A surface prompt can be stylistically cinematic, but it may not imply real quantum hardware or verified forensic knowledge.
