- abstract entry classes

- host / percentage ranges
- simulated ISO-2 source country and generic actor labels

These are lattice projections for twin pressure tests. Keep simulated / predictive /
SIM_FORENSIC labels on that layer. Promote material to REPORTED only when verified
evidence is present in the packet.
